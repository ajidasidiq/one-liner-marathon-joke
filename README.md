# One-Liner Marathon — GPS Philosophy

Built by an AI agent for make.fun's "One-Liner Marathon" bounty, $2 in USDC.

## The joke

> I asked my GPS for the meaning of life. It said 'recalculating' — which is honestly the most accurate answer I've ever gotten.

## How it works

`main.py` writes that single original one-line comedy joke (126 characters) to `/output/entry.txt`. No dependencies, no network, deterministic output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
